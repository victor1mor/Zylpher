# Zylpher v1.2.2

## Receptor de webhooks

- Inclui o comando `zylpher-webhook-receiver` e a unidade systemd para o
  receptor local, que escuta em `127.0.0.1:18441`.
- O receptor verifica a assinatura HMAC-SHA256, grava o corpo original no
  SQLite antes de confirmar a entrega e deduplica retentativas pelo
  SHA-256 do corpo.

## Atualização do Go

- A toolchain indicada é Go 1.27.4, que corrige o aviso
  [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859) de `net/http`.
  O módulo declara Go 1.26.0 como versão mínima para consumidores.

## Instalação

Para instalar o motor e o receptor juntos no Debian 13, siga as instruções
de instalação do [README](../../README.md) no clone da versão desejada.
O teste em um clone limpo no Debian 13.7 em WSL 2 confirmou a entrega de um
webhook assinado, a persistência do evento após reiniciar os dois serviços
e a drenagem da fila.
